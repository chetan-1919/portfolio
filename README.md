# Sai — Personal Portfolio

Dark futuristic developer portfolio built with React + Vite.

## Run locally

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Add your profile photo

Put your image at:

`public/profile.jpg`

The portfolio already contains the photo placeholder and will automatically display the image when that file exists.

## Update projects

Edit the project cards in `src/main.jsx` and add your GitHub/demo links as you publish projects.
